# 0.5.0

Search validates complete copied and correction evidence before filling lexical, core,
procedure, graph and vector windows. Invalid transferred evidence no longer hides
independent valid results at small result limits.

Adds `MemorySearchBudgetExceededException` for shared candidate, source-read and
materialized-payload allowances. Exhaustion is an explicit failure, not an empty answer.
This additive public API requires matching 0.5.0 packages. Broker SDK minimum remains
3.30.0. Local verification and package publication are separate.
