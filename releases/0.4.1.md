# 0.4.1

Core, claim, procedure and graph searches check direct secondary contributors before
candidate limits. Missing, foreign, suppressed, future or expired contributors no longer
hide a valid result behind an invalid candidate. Graph roots and edge endpoints receive
the same checks. Exact valid-time boundaries and offsets are preserved.

Full sealed transfer lineage, sensitivity and current audience authorization remain
authoritative after selection. This release does not remove runtime context rotation.
