# 0.3.1

- Bind derived evidence verification to the exact source fingerprint it verified. `MemorySourceIntegrity.Seal` and store resolution clear earlier results, so a copied or corrected episode whose ancestry is changed and resealed by a caller is no longer treated as verified until a store resolves it again.
- Store resolution now records retained-certificate integrity separately from current recall eligibility. Suppressed, expired or revoked copies and corrections with an intact sealed certificate remain available to authorized export inspection; recall eligibility is unchanged.
- Export audience projection hides transfer and correction episodes whose retained certificate does not verify, together with every contributor-dependent entity, claim, edge, block, procedure and embedding. An independently resealed correction with missing or altered contributors, or with omitted inherited shared restrictions, can no longer be exported from a damaged or imported store.
- No public API, JSON shape, fingerprint format or database schema changes. Deploy with matching platform and agent package pins.
