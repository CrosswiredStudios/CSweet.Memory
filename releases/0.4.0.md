# 0.4.0

Targeted core searches match block names and content before limiting results. Unrelated
pinned preferences no longer accompany every search. `MemorySearchRequest.IncludePinnedCore`
explicitly includes persistent pinned context, and `MemoryEngine.RecallAsync` opts in for
normal context assembly. Existing source, sensitivity, confirmation and audience checks apply.

Both stores add populated, atomic core-search indexes that remain synchronized for older
writers. All six packages use 0.4.0. Publish matching packages together before downstream
release builds; this change does not remove runtime-wide private-context rotation.
